# AI 회화 친구

배우고 싶은 언어로 천천히 말을 걸어 주는 AI 친구 앱이에요. 듣기 → 따라 말하기 → 읽기 → 쓰기 순서로 연습해요.

## 휴대폰에 설치하기
1. 휴대폰 브라우저로 이 앱 주소를 열어요. (안드로이드는 크롬, 아이폰은 사파리)
2. 안드로이드: 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
   아이폰: 공유 버튼 → **홈 화면에 추가**
3. 홈 화면의 아이콘을 누르면 앱처럼 열려요.
4. 톱니바퀴 → AI 연결에 [Google AI Studio](https://aistudio.google.com/apikey)에서 받은 무료 Gemini 키를 넣어요. 키는 그 휴대폰 안에만 저장돼요.

## 업데이트
이 저장소에 새 파일이 올라오면, 휴대폰 앱은 인터넷에 연결된 상태로 열 때 새 버전을 받아요. 따로 할 일은 없어요.
지금 버전은 `VERSION` 파일과 앱의 설정 화면 맨 아래에 적혀 있어요.

## 파일
- `index.html` — 앱 화면 전체
- `manifest.webmanifest` — 앱 이름·아이콘·전체 화면 설정
- `sw.js` — 새 버전을 받아 오고, 인터넷이 끊겼을 때도 열리게 해 주는 파일
- `icon-*.png`, `apple-touch-icon.png` — 홈 화면 아이콘

마음대로 쓰고, 고치고, 나눠도 돼요.
